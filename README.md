# VLSI-Projects

RTL design and verification projects built during my VLSI Mentorship Internship at Apsis Solutions, using Verilog/SystemVerilog with self-checking testbenches and simulation in Xilinx Vivado.

## Projects

| Project | Description | Tools |
|---|---|---|
| [16-Bit RISC Processor](./16-Bit_RISC_Processor) | Custom 10-instruction ISA (R/I/J-type), Harvard architecture single-cycle datapath | Verilog, Xilinx Vivado |
| [Sequence Detector (1101)](./Seq_detector_1101) | Overlapping pattern detector — Mealy & Moore FSM implementations | Verilog, Xilinx Vivado |
| [Vending Machine Controller](./Vending_machine) | FSM-based controller with coin debouncing (2-FF synchronizer) and card payment extension | Verilog, Xilinx Vivado |
